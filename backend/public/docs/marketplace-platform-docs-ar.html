٢. حراسات المصادقة والوسيط

تستخدم المنصة نظام الحارس المتعدد في Laravel مع 7 حراسات مصادقة مختلفة — واحد لكل نوع مستخدم. كل حارس له نموذج Eloquent خاص به، ومحرك جلسة، ووسيط مرتبط. يتم التحكم في وصول المسؤول بالإضافة إلى ذلك عبر Spatie RBAC.
