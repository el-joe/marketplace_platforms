Routes & Pages

Storefront Pages (web.php)

/classifieds
P2P Classified Listings

Browse peer-to-peer listings. Filter by category, location. Map-based view. Submit inquiries. Supports image + contract attachments.

/travel
Travel Package Booking

Browse travel packages from agencies. View details, media, pricing. Book with confirmation flow.

/try-on/{listing}
AI Virtual Try-On

Customer uploads a photo → AI overlays the product → returns try-on result images. Session stored in DB.

/radio/{country}
Internet Radio

Country-specific radio channels. Scheduled programming. Listen session analytics tracked per user.

/now-nawy
Admin Curated Feed

Admin-hand-picked product listings displayed as a curated feed. Browsable by category.

/r/{slug}
Marketer Tracking Redirect

Intercepts marketer referral links, logs click with TrackMarketerClick middleware, then forwards to product page.
