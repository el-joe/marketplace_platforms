Key Subsystems

Order & Fulfillment Pipeline

Master Order splits into per-vendor SubOrder records. Each SubOrder progresses through statuses: pending → confirmed → processing → shipped → delivered.

Fulfillment options: (1) Direct vendor drop-ship, (2) FBN (Fulfillment by Noon) using platform warehouses, (3) Last-mile delivery via DeliveryAgent network.

Financial flow: Order → Commission calculation → Payout accumulation → Scheduled payout disbursement. SLA monitoring via CheckSlaBreachJob.

Flash Sales System
Admin creates flash sales → invites eligible vendors → vendors submit listings with prices → admin reviews submissions → approved listings go live. State machine manages transitions. Real-time analytics via live monitor endpoint. Bulk operations supported for large vendor pools.
Affiliate / Marketer System
Marketers promote products via unique URLs (/r/{slug}), QR codes, and WhatsApp links. Clicks are tracked → converted to commissions on completed orders → tiered commission rates → admin approves payouts. Secret promotions let vendors offer exclusive deals to specific marketers.
AI Feature Suite
  • Image Enhancement: Queue-based AI image quality improvement for vendor product photos.
  • Video Generation: AI-powered product video creation from images.
  • Virtual Try-On: Customer-facing (/try-on/{listing}) — upload a photo, see yourself in the product.
  • Credit System: Vendors purchase AI feature credits; consumption tracked per job.
Page Builder CMS
Admin can compose dynamic storefront pages using a block-based builder. Each Page contains multiple PageBlocks (product grids, banners, carousels, seller spotlights, category showcases). Blocks have revision history, country/customer-segment visibility controls, drag-drop reordering, and live preview.
