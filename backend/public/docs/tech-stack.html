Architecture Notes

Template Engine

Laravel Blade with Alpine.js for reactive components. No SPA framework — server-rendered with sprinkled reactivity.

Queue Backend

Laravel Queues (database or Redis driver). 34 background jobs handle async tasks from AI processing to notification dispatch.

Database

MySQL / PostgreSQL via Laravel Eloquent ORM. 187 migrations, UUIDs for primary keys, soft deletes on core entities.
