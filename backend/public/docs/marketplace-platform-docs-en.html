2. Authentication Guards & Middleware

The platform uses Laravel's multi-guard system with 7 distinct auth guards — one per user type. Each guard has its own Eloquent model, session driver, and associated middleware. Admin access is additionally controlled via Spatie RBAC.

2.1 Auth Guards

Guard NameDriverEloquent ModelPortal
websessionCustomerStorefront — shoppers
adminsessionAdminAdmin panel — platform management
vendorsessionVendorAdminPartner portal — vendor team members
deliverysession + SanctumDeliveryAgentDelivery agent app — also supports API tokens
marketersessionMarketerMarketer portal — affiliates and influencers
travel_agencysessionTravelAgencyTravel agency portal
