Authentication

Guards, Middleware & Auth

The platform uses Laravel's multi-guard authentication system with 7 distinct user types, each with its own session guard, Eloquent model, and middleware.

Auth Guards

Guard Name Driver Eloquent Model Portal / Use
web session Customer Storefront — shoppers browsing and placing orders
admin session Admin Admin panel — full platform management with Spatie RBAC
vendor session VendorAdmin Partner portal — vendor team members managing the store
delivery session + Sanctum DeliveryAgent Delivery app — mobile agents, also supports API tokens
marketer session Marketer Marketer portal — affiliates and influencers
travel_agency session TravelAgency Travel agency portal — package management
shipping_supervisor session ShippingCompanySupervisor Carrier portal — shipping company supervisors

Custom Middleware

AdminAuth

Enforces auth:admin guard on all admin routes. Redirects unauthenticated requests to admin login.

VendorAuth

Enforces auth:vendor guard. Used on all partner portal routes.

DeliveryAuth

Enforces auth:delivery guard for delivery agent sessions.

MarketerAuth

Enforces auth:marketer guard for the affiliate portal.

TravelAgencyAuth

Enforces auth:travel_agency guard.

ShippingCompanySupervisorAuth

Enforces auth:shipping_supervisor guard.

CheckAdminPermission

Checks Spatie permission names on individual admin routes. Granular RBAC beyond just role-level access.

VendorActive / VendorOnboarded

Ensures vendor account is active and has completed onboarding before accessing partner portal features.

SetLocale / SetVendorLocale

Sets App::setLocale() based on user preference. Supports en and ar.

SubdomainDetect

Reads the incoming subdomain to route requests to the correct portal context.

TrackMarketerClick

Intercepts /r/{slug} redirects to log a MarketerClick before forwarding to the product page.

Admin RBAC (Spatie)

The Admin model uses spatie/laravel-permission for fine-grained role-based access control.

  • → Roles and permissions stored in roles, permissions, model_has_roles, model_has_permissions tables.
  • → Admins can be assigned multiple roles (e.g. super-admin, finance-manager, support-agent).
  • → CheckAdminPermission middleware enforces per-route permission checks.
  • → Admin impersonation feature allows admins to act as vendors for debugging.
  • → Login sessions are logged in admin_login_sessions for audit trail.

API Authentication (Sanctum)

The REST API (/api/v1/*) uses Laravel Sanctum token-based authentication.

  • → DeliveryAgent mobile app authenticates via auth:sanctum guard.
  • → Tokens are long-lived and associated to the delivery_agents user provider.
  • → Token abilities can be used for scoped access control.
