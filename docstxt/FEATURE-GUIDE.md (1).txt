2. المشاهير والوسطاء
إعداد ملف المشهور (الأدمن)
admin.noon.codefanz.com/marketers/{id}/edit


حقول المشهور:


* ad_price BIGINT + ad_price_currency + can_self_edit_ad_price
* commission_discount_type (none/flat/percentage) + commission_discount_flat + commission_discount_percentage + commission_discount_notes


مقاسات العينات للمشهور:


* clothing_size, shirt_size, pants_size, dress_size, abaya_size
* shoe_size, shoe_size_system (EU/US/UK)
* chest_cm, waist_cm, hip_cm, height_cm, item_length_cm
* sleeve_from_neck_cm, sleeve_from_shoulder_cm, sleeve_width_cm, measurements_notes


حقول الوسيط:


* broker_category_id — القسم المتخصص
* broker_city_id — مدينة محددة
* broker_serves_all_cities — true = كل المدن
المشهور يعدّل سعره
marketer.noon.codefanz.com/profile


PUT /marketer/profile/ad-price


body: { ad_price: BIGINT, ad_price_currency: "OMR" }


(يشترط can_self_edit_ad_price = true)
قائمة المشاهير للعميل
noon.codefanz.com/uae-ar/marketers


GET /api/public/v1/{region}/marketers
صفحة بروفايل المشهور
noon.codefanz.com/uae-ar/marketer/{slug}


GET /api/public/v1/{region}/marketers/{slug}


* القسم A: منتجاته الشخصية (invitation_id IS NULL)
* القسم B: منتجات الحملات (invitation_id IS NOT NULL)
* السعر الإعلاني في الـ sidebar

7. منتجات التفصيل والمدخلات المخصصة
البائع يُضيف حقولاً
partner.noon.codefanz.com/listings/{id}


← بطاقة "Custom Order Fields" → Toggle ON → Add field


POST /partner-api/products/{id}/custom-attributes


body: { label: "عرض الصدر", unit: "cm", is_required: true }
الأدمن يُفعّل على مستوى المنتج
admin.noon.codefanz.com/products/{id}/edit


← Classification card → "Has Custom Attributes" Toggle
للعميل
* يظهر Modal عند إضافة للسلة
* الحقول المُعلَّمة Required إلزامية
* القيم محفوظة في cart_item_custom_attribute_values ثم order_item_custom_attribute_values


تظهر في الطلبات:


* admin.noon.codefanz.com/orders/{id}
* partner.noon.codefanz.com/orders/{id}
* noon.codefanz.com/uae-ar/profile/orders/{id}


إصلاح: FloatingCartButton (موبايل) الآن يُمرّر الحقول صحيحاً — كان يُرسل بدون custom_attribute_values ويُعطي خطأ custom_attribute_required.
